# 🎓 SOC Analyst Path — Let’sDefend
A comprehensive hands‑on learning journey completed through the **Let’sDefend SOC Analyst Path**, focused on developing real-world Security Operations Center skills through guided labs, simulations, and practical case investigations.

---

## 🧭 Objective
The purpose of this learning path was to build a strong foundation in SOC operations by working through real-world detection scenarios, malware alerts, incident response workflows, and SIEM-based investigations.  
The curriculum emphasized hands-on security analysis, case handling, and threat validation—mirroring the responsibilities of a Tier 1 / Tier 2 SOC Analyst.

---

## 🧠 Skills Learned
Throughout the SOC Analyst Path, I gained practical, job‑ready skills:

### **Core SOC Skills**
- Alert triage and prioritization  
- False-positive identification and validation  
- Endpoint and network log analysis  
- Threat intelligence enrichment using OSINT sources  
- Correlating SIEM alerts with host behavior  
- Understanding common attack patterns and IOC types  

### **Technical Skills**
- Malware analysis (static and behavioral)  
- Phishing investigation and header analysis  
- Windows event log and Sysmon analysis  
- Network traffic interpretation  
- URL and file reputation investigation  
- MITRE ATT&CK technique mapping  

### **Operational Skills**
- Case documentation and analyst notes  
- Incident escalation workflow  
- Evidence gathering and timeline reconstruction  
- Applying security controls based on detection type  
- Professional reporting for SOC workflows
